# Paper and textbook

This directory contains the two PDFs used by this Lean companion.

| File | Reference and reading location |
| --- | --- |
| [Yau-Conjecture.pdf](Yau-Conjecture.pdf) | Guorui Ma, *Non-existence of Negative Weight Derivations of the Moduli Algebras of Isolated Weighted Homogeneous Hypersurface Singularities*. Sections 2–4 contain the proof; Appendices A–B give the supporting algebra. |
| [AGV-Volume-2.pdf](AGV-Volume-2.pdf) | V. I. Arnold, S. M. Gusein-Zade, A. N. Varchenko, *Singularities of Differentiable Maps, Volume 2: Monodromy and Asymptotics of Integrals*. Modern Birkhäuser Classics, reprint of the 1988 edition. Theorem 14.8 is on printed p. 415, PDF page 424; deformation and versality are discussed in Section 3.1, printed pp. 67–68, PDF pages 78–79. |

The [proof guide](../docs/Proof.md) follows the paper's numbering. The [textbook guide](../docs/AGV.md) explains the use of Theorem 14.8. Both PDFs retain their original contents and respective publication notices.
