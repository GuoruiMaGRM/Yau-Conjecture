# Reading the Lean code

Read the [proof guide](Proof.md) first for the argument. This page then tells you where each step is implemented and what the supporting files contribute. All source links below are relative to [`RequestProject/Yau/`](../RequestProject/Yau/), except the entry point.

The library contains the entry point and 59 modules. Its mathematical definitions use the same objects as the paper: the Jacobian ideal, the Milnor algebra, weighted homogeneous components, and homogeneous derivations.

## How to read the directory

Each Lean file proves one part of the argument and imports the results it needs from other files. The complete entry point is [`RequestProject/Yau.lean`](../RequestProject/Yau.lean). To read the mathematics, follow the sections below in the order of the paper.

| Directory | Meaning and purpose |
| --- | --- |
| `Basic/` | Definitions and basic calculations: weighted degrees, the Jacobian ideal, Milnor algebras, and derivations. |
| `Sec2_Splitting/` | `Sec2` means Section 2 of the paper; splitting removes the quadratic variables. |
| `Sec3_Radical/` | Section 3: the radical of the ideal generated by the selected partial derivatives. |
| `Sec4_Proof/` | Section 4: the orbit argument and the final contradiction. |
| `Analytic/` | Analytic functions, convergent Taylor series, and local Milnor numbers. |
| `Versality/` | The analytic coordinate changes that express the families needed here through the monomial-basis deformation. |
| `Appendix/` | The local-algebra comparisons and derivation results used from Appendices A–B. |
| `CommAlg/` | Commutative algebra: regular sequences, their relations, and quotient-dimension arguments. |
| `Final/` | Connects the component results to the main theorem and its textbook hypothesis. |
| `LowDim/` | Special cases and additional criteria, including at most three variables and equal weights. |

Some filenames use standard abbreviations. `Poly` means polynomial, `Subst` means substitution, and `OneVar` and `ThreeVar` mean one variable and three variables. `LocalMilnor` refers to the Milnor number at a specified point. A `Jet` is a Taylor expansion kept only up to a finite order. The file tables explain what each of these constructions contributes to the proof.

The name **`AGV148.lean`** refers to **Theorem 14.8 in Volume 2 of the textbook by Arnold, Gusein-Zade, and Varchenko (AGV)**. The theorem describes the constant-Milnor-number stratum by the vanishing of certain deformation parameters. This is the textbook input used to prove the paper's Lemma 3.4. The detailed statement and the relevant textbook pages are in the [textbook guide](AGV.md).

## Main theorem

Start at [`Final/ThreeNewLocal.lean`](../RequestProject/Yau/Final/ThreeNewLocal.lean). The exact declaration for the main theorem is **`Yau.yau_conjecture_of_agv148`**. It takes the textbook statement as the explicit argument

```lean
hA : ∀ m, 2 ≤ m → Yau.AGVTheorem148For m
```

In that line, `AGVTheorem148For m` is the Lean proposition expressing the textbook statement for a polynomial in `m` variables. The word `For` indicates that the number of variables is an argument. The argument `hA` supplies this statement for every `m` at least two; the zero- and one-variable cases are proved directly in the library.

Here is how the relevant files connect. `AGV148.lean` states the textbook input precisely. `Versality/FixedPoint.lean` constructs the required coordinate changes for families whose critical point stays at the origin. `ThreeNewLocal.lean` uses both results to prove Lemma 3.4 and then assembles the main theorem; `ThreeNew.lean` supplies the application to the square family in Corollary 3.5. In these descriptions, **local** means that the critical-point and Milnor-number conditions are stated at the origin and near the zero parameter; the **global** formulation controls all critical points of the polynomial. Both formulations have explicit hypotheses.

The remaining arguments say that the weights are positive, `f` is weighted homogeneous, the origin is an isolated critical point, and `δ` is a derivation of degree `k < 0`. The conclusion is `δ = 0`.

To follow how this theorem is obtained, use this reading order:

1. [`Basic/Basic.lean`](../RequestProject/Yau/Basic/Basic.lean): identify the algebra and grading in the statement.
2. [`Final/AGV148.lean`](../RequestProject/Yau/Final/AGV148.lean): read the precise textbook hypothesis.
3. [`Final/ThreeNewLocal.lean`](../RequestProject/Yau/Final/ThreeNewLocal.lean): see how it implies the local Lemma 3.4.
4. [`Final/ThreeNew.lean`](../RequestProject/Yau/Final/ThreeNew.lean): follow the application to the square deformation and Corollary 3.5.
5. [`Sec3_Radical/Radical.lean`](../RequestProject/Yau/Sec3_Radical/Radical.lean): see Theorem 3.6 exclude the radical element.
6. [`Sec4_Proof/Core.lean`](../RequestProject/Yau/Sec4_Proof/Core.lean) and [`MainTheorem.lean`](../RequestProject/Yau/Sec4_Proof/MainTheorem.lean): follow the contradiction and the splitting induction.

The rest of this page follows the paper's order rather than the order of imports.

## Introduction: definitions and analytic language

The proof moves between polynomial calculations and analytic local algebras. These files define both settings and establish their basic operations.

| File | Role in the proof |
| --- | --- |
| [Basic/Basic.lean](../RequestProject/Yau/Basic/Basic.lean) | Introduces the polynomial ring, the Jacobian ideal generated by the partial derivatives, its quotient Milnor algebra, and the weighted grading. These definitions express the statement that a negative-degree derivation must vanish. |
| [Basic/PolyDeriv.lean](../RequestProject/Yau/Basic/PolyDeriv.lean) | Constructs a polynomial derivation from its coefficient polynomials. It proves how applying the derivation changes weighted degree, which makes the negative-degree derivations in Sections 2 and 4 locally nilpotent. |
| [Basic/PolyCalculus.lean](../RequestProject/Yau/Basic/PolyCalculus.lean) | Shows that formal differentiation of a polynomial agrees with differentiation of the corresponding complex function. This lets the proof pass between polynomial identities and analytic critical-point conditions. |
| [Basic/Setup.lean](../RequestProject/Yau/Basic/Setup.lean) | Collects the assumptions available after quadratic variables have been removed. It also names the square-deformation conclusion of Corollary 3.5, so that the radical proof can use it as one input. |
| [Basic/Convergent.lean](../RequestProject/Yau/Basic/Convergent.lean) | Defines the ring of convergent power series and the map sending a polynomial to its power series. This supplies the analytic local ring used to define the Milnor algebra in the paper. |
| [Analytic/Expansion.lean](../RequestProject/Yau/Analytic/Expansion.lean) | Associates a convergent Taylor series to an analytic function and proves that it represents the function near the expansion point. It allows statements about analytic functions to be used in the local power series ring. |
| [Analytic/LocalMilnor.lean](../RequestProject/Yau/Analytic/LocalMilnor.lean) | Defines the local Milnor number at a specified critical point and proves that an invertible analytic change of coordinates preserves it. This is needed when versality changes coordinates in Lemma 3.4. |

## Section 2: remove quadratic variables and select D

The first six files below implement weight-preserving substitutions and the removal of variables. The last file makes the minimum-degree choice that gives $`D^2f=0`$.

| File | Role in the proof |
| --- | --- |
| [Sec2_Splitting/Elementary.lean](../RequestProject/Yau/Sec2_Splitting/Elementary.lean) | Proves elementary polynomial facts used to remove variables: setting a coordinate to zero, recognizing independence of a variable, dividing by a coordinate, and expanding a quadratic expression. |
| [Sec2_Splitting/Subst.lean](../RequestProject/Yau/Sec2_Splitting/Subst.lean) | Proves the chain rule for polynomial substitutions and tracks the Jacobian ideal and weighted degree through them. These facts justify the coordinate changes in Lemma 2.1. |
| [Sec2_Splitting/Transfer.lean](../RequestProject/Yau/Sec2_Splitting/Transfer.lean) | Transfers the Milnor algebra and its derivations through a graded algebra isomorphism. Consequently, proving the theorem after a splitting step proves it for the polynomial before that step. |
| [Sec2_Splitting/Reduction.lean](../RequestProject/Yau/Sec2_Splitting/Reduction.lean) | Constructs the elementary coordinate changes and the maps to polynomial rings with fewer variables. These are the actual maps used in each splitting step. |
| [Sec2_Splitting/Steps.lean](../RequestProject/Yau/Sec2_Splitting/Steps.lean) | Carries out the two cases of Lemma 2.1: removing a square term and removing a term pairing two variables. It checks that the required coefficients are nonzero using isolatedness. |
| [Sec2_Splitting/Splitting.lean](../RequestProject/Yau/Sec2_Splitting/Splitting.lean) | Packages the removal of a quadratic variable or a pair of variables together with the resulting Milnor-algebra comparison. Section 4 applies these steps repeatedly by induction. |
| [Sec2_Splitting/Minimum.lean](../RequestProject/Yau/Sec2_Splitting/Minimum.lean) | Implements the least-degree choice in Proposition 2.4. Starting from a nonzero negative-degree derivation, it selects one satisfying the extra vanishing condition needed for the orbit argument. |

## Section 3: the Hessian, square deformation, and radical theorem

These modules provide the two sides of the small-degree contradiction and the direct large-degree argument. Lemma 3.4, which connects the square deformation to ideal membership, is listed separately just below.

| File | Role in the proof |
| --- | --- |
| [Sec3_Radical/Taylor.lean](../RequestProject/Yau/Sec3_Radical/Taylor.lean) | Expands a polynomial to second order in a direction when the relevant third derivatives vanish. This expresses the quadratic dependence used in the Hessian argument. |
| [Sec3_Radical/LowestOrder.lean](../RequestProject/Yau/Sec3_Radical/LowestOrder.lean) | Takes the first nonzero homogeneous part of a polynomial identity. This produces the nonzero vector needed to contradict degeneracy of the selected Hessian block. |
| [Sec3_Radical/Hessian.lean](../RequestProject/Yau/Sec3_Radical/Hessian.lean) | Proves the polynomial Hessian nondegeneracy statement needed from Lemma 3.1. It rules out the cancellation that would otherwise allow a small-degree square to lie in the Jacobian ideal. |
| [Sec3_Radical/SquareDeformation.lean](../RequestProject/Yau/Sec3_Radical/SquareDeformation.lean) | Studies the family obtained by adding a parameter times a square. Under the hypotheses used in Lemma 3.3, it proves equality of the Jacobian radicals, so the critical-point set is preserved. It also supplies a homogeneous-component calculation used for ideal membership. |
| [Sec3_Radical/MilnorConstancy.lean](../RequestProject/Yau/Sec3_Radical/MilnorConstancy.lean) | Shows that the polynomial Jacobian quotient has the required constant dimension under lower-degree perturbations. Together with the critical-point calculation, this proves constant local Milnor number for the square family used in Corollary 3.5. |
| [Sec3_Radical/Radical.lean](../RequestProject/Yau/Sec3_Radical/Radical.lean) | Proves the square exclusion in Lemma 3.2 and combines the small-degree contradiction with the direct large-degree argument to obtain Theorem 3.6. This is the radical statement used in the final contradiction. |

### Lemma 3.4 and the textbook input

The formalization proves the first-order consequence through a monomial-basis deformation, invariance of the local Milnor number, and a right-equivalence construction. The following files are its main components.

| File | Role in the proof |
| --- | --- |
| [Final/AGV148.lean](../RequestProject/Yau/Final/AGV148.lean) | AGV names Arnold, Gusein-Zade, and Varchenko; 148 refers to their textbook Theorem 14.8. This file states its precise neighborhood form as `Yau.AGVTheorem148For`, relates it to the stratum inclusion used in the proof, and proves the zero- and one-variable cases directly. |
| [Final/ThreeNew.lean](../RequestProject/Yau/Final/ThreeNew.lean) | States the linear-deformation conclusion of Lemma 3.4 in local and global forms. It proves the zero- and one-variable cases and shows how the conclusion supplies Corollary 3.5 and then the main theorem. |
| [Final/ThreeNewLocal.lean](../RequestProject/Yau/Final/ThreeNewLocal.lean) | Connects the local and global formulations of Lemma 3.4, derives the lemma from the AGV textbook input, and assembles the main theorem `Yau.yau_conjecture_of_agv148`. This is the main result to read alongside the paper. |
| [Sec3_Radical/Corollary35.lean](../RequestProject/Yau/Sec3_Radical/Corollary35.lean) | The number 35 refers to Corollary 3.5 of the paper. This file builds the monomial-basis miniversal deformation and proves the parameter-vanishing and differentiation steps. It also treats a general-versality formulation; the main theorem uses the fixed-origin construction in `Versality/FixedPoint.lean`. |
| [Versality/Tools.lean](../RequestProject/Yau/Versality/Tools.lean) | Provides analytic inverse maps, Taylor remainder formulas, and bounds for nilpotent elements. These are the auxiliary tools used to construct the coordinate changes expressing versality. |
| [Versality/Jet.lean](../RequestProject/Yau/Versality/Jet.lean) | A jet is a Taylor expansion truncated at a finite order. This file first solves the deformation problem at that finite order, producing the parameter curve and the first-order identity needed in Lemma 3.4. |
| [Versality/Determinacy.lean](../RequestProject/Yau/Versality/Determinacy.lean) | Finite determinacy allows sufficiently high finite-order information to determine right equivalence. This file proves the Tougeron statement used to turn the jet construction into an actual analytic change of coordinates. |
| [Versality/FixedPoint.lean](../RequestProject/Yau/Versality/FixedPoint.lean) | Here the fixed point is the origin, which remains a critical point throughout the family. The file combines the jet and determinacy arguments to prove versality for these families, then derives their first-order Jacobian-ideal conclusion from the stratum hypothesis. |

### Supporting modules for the stratum's reverse inclusion

The main argument uses $`\Sigma_\mu\subseteq E`$ from the textbook. The library also proves $`E\subseteq\Sigma_\mu`$ directly. The following modules establish that inclusion and the resulting equivalence of the two hypothesis formulations.

| File | Role |
| --- | --- |
| [Sec3_Radical/WeightFiltration.lean](../RequestProject/Yau/Sec3_Radical/WeightFiltration.lean) | Organizes polynomials by lower bounds on the weights of their terms. It tracks those bounds under multiplication and differentiation, preparing the estimates for higher-weight perturbations. |
| [Sec3_Radical/LemmaC1.lean](../RequestProject/Yau/Sec3_Radical/LemmaC1.lean) | Proves the polynomial comparison needed for a perturbation consisting only of terms of higher weight. It compares truncated Jacobian quotients by reducing relations among the partial derivatives. The following local file converts this calculation into a Milnor-number statement. |
| [Sec3_Radical/LemmaC1Local.lean](../RequestProject/Yau/Sec3_Radical/LemmaC1Local.lean) | Proves that the origin remains an isolated critical point after the higher-weight perturbation and that its local Milnor number equals that of the unperturbed weighted homogeneous polynomial. This supports the reverse stratum inclusion. |
| [Sec3_Radical/HilbertFunction.lean](../RequestProject/Yau/Sec3_Radical/HilbertFunction.lean) | Computes dimensions of the homogeneous pieces of the Jacobian quotient. It shows that isolated weighted homogeneous polynomials with the same weights and degree have Milnor algebras of the same dimension. |
| [Sec3_Radical/Openness.lean](../RequestProject/Yau/Sec3_Radical/Openness.lean) | Shows that sufficiently small homogeneous perturbations of the same weighted degree preserve isolatedness. This provides a neighborhood on which the reverse stratum inclusion can be proved. |
| [Sec3_Radical/VarchenkoInclusion.lean](../RequestProject/Yau/Sec3_Radical/VarchenkoInclusion.lean) | Combines the perturbation and dimension results to prove that the specified coordinate subspace lies in the zero-critical-value, constant-Milnor-number stratum. This is the reverse inclusion, proved in the library for every number of variables. |
| [Sec3_Radical/VarchenkoOneVar.lean](../RequestProject/Yau/Sec3_Radical/VarchenkoOneVar.lean) | OneVar means one variable. The file identifies the local Milnor number with root multiplicity and proves the stratum statement directly in one variable, together with its zero-variable case. |

## Section 4: the orbit argument and the contradiction

| File | Role in the proof |
| --- | --- |
| [Sec4_Proof/Orbit.lean](../RequestProject/Yau/Sec4_Proof/Orbit.lean) | Constructs the polynomial orbits of the locally nilpotent derivation and their weighted degeneration. This proves the radical-membership consequence of Lemma 4.1 used by the main argument. |
| [Sec4_Proof/Quotient.lean](../RequestProject/Yau/Sec4_Proof/Quotient.lean) | Proves the calculations in Lemma 4.3: the selected partial-derivative ideal is preserved, and the second derivatives along the chosen derivation vanish in its quotient. These conditions allow the orbit argument to apply. |
| [Sec4_Proof/Core.lean](../RequestProject/Yau/Sec4_Proof/Core.lean) | Chooses a variable of least weight moved by the derivation. The orbit result places its nonzero image in the homogeneous part of a radical excluded by Theorem 3.6, giving the contradiction after quadratic-variable removal. |
| [Sec4_Proof/MainTheorem.lean](../RequestProject/Yau/Sec4_Proof/MainTheorem.lean) | Uses induction on the number of variables to combine the splitting steps with the core contradiction. It restores the general polynomial theorem from the reduced case. |
| [Final/MainResult.lean](../RequestProject/Yau/Final/MainResult.lean) | Connects the stratum statement to the square-deformation conclusion used by the core proof. It then packages the integer-weight, rational-weight, and moduli-algebra forms of the theorem. |
| [Final/Rational.lean](../RequestProject/Yau/Final/Rational.lean) | Clears denominators of rational weights and checks that this preserves the sign of the derivation degree. This transfers the integer-weight result to rational weights. |

## Appendices A–B: local algebras and derivations

| File | Role in the proof |
| --- | --- |
| [Appendix/Isolated.lean](../RequestProject/Yau/Appendix/Isolated.lean) | Relates isolated critical points to the radical of the Jacobian ideal and finite dimension of the polynomial Milnor algebra. This connects the geometric and algebraic assumptions used throughout the proof. |
| [Appendix/AnalyticMilnor.lean](../RequestProject/Yau/Appendix/AnalyticMilnor.lean) | Compares a polynomial quotient with the corresponding convergent-power-series quotient when the ideal contains suitable powers of the coordinates. Finite Taylor truncation makes the comparison possible. |
| [Appendix/AnalyticYau.lean](../RequestProject/Yau/Appendix/AnalyticYau.lean) | Applies the preceding quotient comparison to the Jacobian ideal. This gives the identification of polynomial and analytic Milnor algebras in Lemma A.1, so the polynomial proof applies to the paper's local algebra. |
| [Appendix/Syzygy.lean](../RequestProject/Yau/Appendix/Syzygy.lean) | A syzygy is a relation among the generators of an ideal. This file proves the low-degree relations and uniqueness statements for the partial derivatives in Lemma B.1, which are needed to lift derivations. |
| [Appendix/EulerModuli.lean](../RequestProject/Yau/Appendix/EulerModuli.lean) | Uses Euler's identity to identify the Milnor and moduli (Tjurina) algebras. It also proves preservation of the maximal ideal under derivations, as in Lemma B.2, and the polynomiality of weighted homogeneous convergent series. |
| [Appendix/Lift.lean](../RequestProject/Yau/Appendix/Lift.lean) | Lifts a negative-degree derivation of the Milnor algebra to a homogeneous polynomial derivation. This supplies the polynomial derivation used in Appendix B and Section 2. |

The regular-sequence arguments use the following algebraic tools.

| File | Role |
| --- | --- |
| [CommAlg/Depth.lean](../RequestProject/Yau/CommAlg/Depth.lean) | CommAlg abbreviates commutative algebra. This file proves depth and regular-element facts for Noetherian local rings, including the Cohen–Macaulay criterion used to establish regular sequences. |
| [CommAlg/RegularSequence.lean](../RequestProject/Yau/CommAlg/RegularSequence.lean) | Shows that the relevant homogeneous systems of parameters form regular sequences. The project applies this to the partial derivatives when computing quotient dimensions and their relations. |

## Additional consequences

These modules give direct proofs in special cases and criteria that can replace the stratum input in those cases. They are included with the library; the reader can follow the general paper proof above independently of them.

| File | Result or criterion |
| --- | --- |
| [LowDim/LowDim.lean](../RequestProject/Yau/LowDim/LowDim.lean) | LowDim abbreviates low dimension, here measured by the number of variables. This file proves the radical result with at most one heavy variable and sets up the induction for bounds on the number of variables. |
| [LowDim/ThreeVar.lean](../RequestProject/Yau/LowDim/ThreeVar.lean) | ThreeVar means three variables. A local Euler argument for one light and two heavy variables completes the proof of Yau's conjecture for at most three variables. |
| [LowDim/Homogeneous.lean](../RequestProject/Yau/LowDim/Homogeneous.lean) | Proves the theorem directly when all variable weights are equal. This is the ordinary homogeneous special case. |
| [LowDim/Restriction.lean](../RequestProject/Yau/LowDim/Restriction.lean) | Proves the radical statement when restricting the polynomial to its heavy coordinates leaves an isolated singularity. This includes the Brieskorn–Pham special case. |
| [LowDim/SmallWeights.lean](../RequestProject/Yau/LowDim/SmallWeights.lean) | Gives a condition on the weights that makes the required radical argument elementary at every degree. Under that condition, the theorem follows directly. |
| [LowDim/QuadraticHeavy.lean](../RequestProject/Yau/LowDim/QuadraticHeavy.lean) | Gives a criterion for the case in which the heavy variables occur quadratically. It combines this with the heavy-coordinate restriction and single-heavy-variable criteria. |
| [LowDim/LocalCriterion.lean](../RequestProject/Yau/LowDim/LocalCriterion.lean) | Turns local square-membership statements into membership in the selected polynomial ideal. It also proves a local Euler criterion with one light variable. |
| [LowDim/LocalLevels.lean](../RequestProject/Yau/LowDim/LocalLevels.lean) | Checks the local and elementary criteria separately at each weighted degree. Satisfying the resulting degree-by-degree condition gives the main theorem. |
| [LowDim/ThomSebastiani.lean](../RequestProject/Yau/LowDim/ThomSebastiani.lean) | Thom–Sebastiani refers here to a sum of polynomials in disjoint variable sets. This file shows how the required local Euler relations pass to such sums, giving another criterion for the theorem. |

Finally, [`RequestProject/Yau.lean`](../RequestProject/Yau.lean) imports all modules and exposes the collected results.
